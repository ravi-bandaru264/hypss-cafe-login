# Hypss-Cafe Management System

Frontend: HTML/CSS/JavaScript | Authentication + DB: Supabase | Deployment: Vercel

## Screens
Login, Dashboard, category menu/item cards, Billing/Create Bill, Orders, Inventory, Reports and Settings.

## Upload to GitHub
1. Download and extract the ZIP.
2. Upload/replace all files in `ravi-bandaru264/hypss-cafe-login` (keep `index.html` at root).
3. Commit to `main`. Vercel should auto-deploy from GitHub.

## Supabase setup
1. Open your Supabase project → SQL Editor and run `supabase-setup.sql`.
2. Authentication → Users → create your administrator email/password.
3. Project Settings → API: copy Project URL and Publishable Key (not service-role key).
4. Paste both into `config.js`.
5. Sign in; then seed category rows by replacing `USER_UUID` in the final commented SQL with your Auth user UUID and executing it.
6. Add menu items in category screens. Billing creates bill records and bill lines. Bill numbers are generated by a database sequence and have a unique constraint.

## Vercel
Framework preset: Other. Build Command: blank. Output Directory: `.`. Install Command: blank.

## Security note
Demo mode is only a UI preview and is not secure authentication or persistent storage. Supabase mode uses Auth and RLS. Before using this as a real POS, add server-side transactional billing/stock updates, staff roles, audit logs, receipt printing, backups and local tax review. Never put a Supabase service-role key in browser files.
